# v1.5.2 — The Model Hub Crash Is Dead

**Released:** 2026-10-21

- THE MODEL HUB CRASH IS DEAD: opening “Modelos & APIs” in v1.5.1 tripped a React hooks violation (the local-models auto-probe ran after the modal's early return), trapping the app in a “Recuperação de Sessão” crash loop — on the home screen AND inside projects. The hook now mounts before the early return; the hub just opens
- EXPORT Z-ORDER FIXED: the bridge emitted tracks bottom-up while the renderer composes top-down, so everything on V2 (motion graphics, b-roll) rendered UNDER the base video — invisible in the exported file even when the preview looked right. The bridge now speaks the store's convention (text first, video and audio descending): overlays actually overlay
- CAPTIONS NOW SHOW IN THE PREVIEW: the harness overlay only drew code clips, so AI-generated captions were invisible on the stage (the export drew them, the preview didn't). Captions and image b-roll now go through the exact same drawing path as the export — preview≡export by construction
- A TIMELINE YOU CAN ACTUALLY EDIT: clip selection, drag with 50 ms snap, edge-trim handles, track change with category clamping (captions can't land on video lanes), delete (Del/Backspace/button) and arrow-key nudge (Shift = 1 s) — the continuous scrub stays intact. The timeline stops being a showcase and becomes an instrument
- MINI-PREVIEW IN THE TIMELINE TAB: a live canvas composites the main video, images, motion graphics and captions in the corner of the Timeline tab — you finally see what you're cutting while you arrange it
- CAPTION POSITION, THE LITERAL ASK (“legendas secas acima da cabeça do personagem”): subtitle_apply_preset accepts position — 'top' (upper third, ideal for 9:16 Shorts with a centered face), 'center', 'bottom', or a top-fraction string like '0.18' — with per-clip posLock, carried through the bridge, and documented in the tool schema so the AI discovers the capability on its own
- PAIRING POLISH: the /pair call in the connection flow now fails in 10 seconds with an honest message (“didn't answer in 10s — looks down”) instead of hanging 1–2 minutes on a dead relay, and the production relay now reports its skipped backlog so the web AI can resend what matters
