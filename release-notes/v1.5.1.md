# v1.5.1 — Pairing That Actually Works

**Released:** 2026-10-21

- PAIRING THAT ACTUALLY WORKS: the Copy button now really copies in the packaged app (Electron file:// was silently killing it — three fallback layers, always with visible feedback), the relay registration happens BEFORE pairing activates (no more 401 on first poll), and the house relay is now the default endpoint in production — pair with the web AI you already use in one paste
