# v1.7.11 — The Field Evaluation Release

**Released:** 2026-11-04

- THE FIELD EVALUATION RELEASE — every fix here comes from the GTA 6 short test session (53 clips, 19.25s, 61 tools, skill v1.9): the external AI left a full bug report (feedback-app-v177.md) and this version is the answer, item by item, with the code map to prove each one.
- THE AGENT'S MIRROR (priority #1 of the field): new tool timeline_capture_composite {at_sec} — composes the MOUNTED frame (background + character + images + captions + motion graphics) through the SAME drawFrame the preview and the export use (one truth, no parallel renderer), canvas 480px, JPEG <=64KB with the quality ladder, travels in bulk.image_base64 for the external AI to SEE. The field proved the AI was editing blind: the owner rejected the layout TWICE (text too big, image too big) and both times the AI had no way to look. Editing blind is over.
- WORD-SYNC THAT FINISHES: the field failed 3/3 with 'turno excedeu o teto de 150s' — the math was impossible (worker ceiling 120s FIXED x fallback chain base->tiny = up to 240s of wall, always above the 150s turn; the skill promised '~2 min' with ZERO margin). Now: (1) the worker ceiling is PROPORTIONAL to audio length (8x duration, floor 120s, cap 300s — subtitles.ts transcribeTimeoutMsFor); (2) a safety timeout is RETHROWN, never swallowed into another full-length retry (the multiplier is dead); (3) the external turn ceiling rose 150s->240s (lease re-deliveries stay deduped by id); (4) if a job still lands late, its FULL payload (words/segments, bounded 120KB with labeled cut) is preserved in ponte_status jobs[].lateResult.data — the comma-summary that threw the segments away is dead.
- THE PHANTOM JOB IS DEAD: a ponte_status/ponte_ping served DURING a heavy turn used to STEAL currentJobIdRef — the transcription progress got attributed to the status command (creating an eternal 'running' ghost) and then dropped to null and discarded. The field read that as 'the job never comes back'. Now the slot is save/restore around meta-actions.
- PLAN GATE x code_* WAS A TRANSPORT BUG: the gate itself accepts deviation_reason uniformly (proven by repro) — what killed the field was (1) the 4.000-char command cap vs the multi-KB tsx_code payload: the AI had to CUT the 'optional' reason to fit and then the gate refused for lack of it; (2) a top-level deviation_reason was silently discarded by the parser. Now: code_inject_to_timeline_track has its own 16.000-char cap (the relay accepts 64k), and a top-level deviation_reason is merged into args. Motion graphics after plan_skip_step: unblocked.
- NO MORE SILENT style LIES: timeline_update_clip with an unknown key (e.g. size instead of font_size) used to return ok:true with changes:[] — the AI believed it applied and the OWNER saw the error in the render. Now the unknown key is REJECTED by name with the right one taught (size -> font_size), and the camelCase gaps (fontSize, strokeW, highlightAnim) are accepted and normalized.
- entrance_animation GAINs delay (0-10s): the field's 'a logo demorou pra aparecer' — the AI delayed the CLIP to make the spin land with the end of the hook words. Now the clip enters at its time and the ANIMATION waits (clip at 0.70s + delay 0.35 = spin starts at 1.05s). Works for every entrance animation including typewriter (same ruler in evaluateClipState and drawTextLayer).
- media_import_local_folder: RELATIVE paths now resolve against the grant root ('Personagem' just works; the field got 'está fora da concessão ativa' for the concession ITSELF because the context only showed the basename), the import is RECURSIVE by default (subfolders come along, cap 50 — the context lists the whole tree, the import used to bring only the root level and the AI lost 5 commands adding poses 'that were not in the library'), and the grant section header now shows the ABSOLUTE path to the external audience.
- NEW media_list (read-only): the ENTIRE session library without budget truncation (exact name for timeline_add_clip) + the grant tree with an imported/not flag — the end of media_name archaeology.
- RELIABILITY RELAY: every bridge fetch now has a 30s AbortSignal (postResult used to hang FOREVER on a half-dead relay — the result was lost and the unconfirmed queue never fed), the stock download body is under the same AbortController as the headers (the field had a 210s download that never answered), and the stock search cache survives renderer reloads (localStorage, rights label travels with the item — 'esta url não vem de uma busca desta sessão' for an asset searched seconds ago is dead).
- subtitle_apply_preset restyle is no longer destructive: clips with individually edited style (styleCustom flag, written by timeline_update_clip) are SPARED and listed (include_styled:true forces) — the red impact stroke the owner approved no longer dies in a global restyle — and the karaoke words SURVIVE the restyle (they used to be silently wiped: real data loss).
- THE CONTRACT TEACHES THE RIGHT PATH NOW (skill.ts, byte-synced to docs + relay): duration_sec AT CREATION for images (the 'born 4.8s, fix with update_clip' workaround is retired), the honest word-sync ceilings, code_* deviation documented, media_list and the mirror documented, per-action command caps, the 240s turn in the limits table.
- VERIFY SUITE GREEN: typecheck clean; ponte-bridge 110/110, ponte-skill 57/57, acc-turn-handlers 107/107, 125/0, context-builder 43/43, ///protocol/plan-mode/host//agente-editor all pass — count assertions updated for the 2 new tools (registry 66->68, bridge-visible 61->63).
