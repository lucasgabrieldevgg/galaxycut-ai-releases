# v1.4.2 — Media Tab

**Released:** 2026-10-10

- MEDIA TAB: the project's media library is now a workspace tab — media no longer disappears after creating an edition; add files anytime (click or drag) and insert any item into the timeline with one button
- CHAT PERSISTS: switching tabs no longer resets the conversation — all views stay mounted and keep their state while you navigate
- SELECTABLE CHAT TEXT: you can now select and copy agent messages (and everything in the chat feed) to report issues
- SESSION MANAGEMENT: rename and delete sessions directly from the home screen (hover a card)
- CLICK TO ADD MEDIA: the create-edition media dropzone now also opens the file picker on click — no more drag-only
