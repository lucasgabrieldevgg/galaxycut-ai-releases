# v1.4.1 — Dark By Default

**Released:** 2026-10-10

- DARK BY DEFAULT: the app now opens in dark mode out of the box — light theme is still one click away and your choice is remembered
- STARTUP AUTO-UPDATE (desktop): every time the app opens it checks for a new version, downloads it automatically with a live progress overlay (%) and restarts itself when done — projects, API keys and settings stay intact
- The updater now runs right after the window loads (plus a safety fallback) and the periodic check no longer pops the manual dialog during the startup flow
- Electron window opens with the dark background color (no white flash), dead component removed, trilingual changelog
