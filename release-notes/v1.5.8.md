# v1.5.8 — The Agent's Folder

**Released:** 2026-10-26

- THE AGENT'S FOLDER: in the chat, /pasta opens a native dialog and YOU point at your bank folder (poses, gameplay, takes). The agent now SEES the file names — the contract the Dynamic Shorts skill already speaks — imports with a REAL probe (duration and dimensions measured, no blind 'video' guesses), and every export defaults to a galaxycut/ subfolder INSIDE your folder: grab from there, edit, re-import. Your folder is read-only territory for the agent except galaxycut/; non-media files are invisible (a count, never names); nothing is ever executed; nothing is overwritten without explicit confirmation; the concession lives in memory only (re-concede with one click each session, revoke anytime from the card). Four new INTERNAL-ONLY tools — the external bridge never learns your folder exists.
- VISUAL QA BEFORE EXPORT: the new timeline_audit_visual tool audits your short BEFORE you export it — cut text, off-canvas/safe-zone escapes, caption overlap in time, WCAG contrast where the background is determinable, empty scenes, video that changed under narration (the exact field case), word-sync drift and audio clipping — with a PCM-tier that actually LISTENS to the flagged stretch (silence detection on real decoded audio, up to 12 medias/60s, above that it falls back to static analysis with an honest note). The typed report (severity, address, suggested fix) lands in the plan card and the AI corrects in sequence; muted b-roll in later slots is a WARNING ('common design — check if intentional'), only a changed clip in slot 0 under narration is an ERROR. 8 checks, 3 languages, zero new hard-coded strings.
- B-ROLL BY KEYWORD AND EDITING THROUGH THE TRANSCRIPT: say 'b-roll de cerejeira' and visual_insert_broll finds EVERY occurrence of the word in the transcription and inserts at the exact time of each one (one download becomes N clips, with a max_insertions guard). The word-sync that used to die with the turn now PERSISTS in the timeline — and the new Transcription tab (⌘8) turns your transcription into CLICKABLE text: click a word, the matching caption clip gets selected and playback jumps to the exact moment of speech; 'Edit on Timeline' opens the properties panel right there. Segments without word timing degrade honestly to segment granularity — no faked proportional timing.
- THE TWO FIELD BUGS ARE DEAD AT THE ROOT: the transcription freeze (bug 3) — a Whisper worker promise with no ceiling could hang forever and freeze the UI and the bridge poller with it; now every supervised transcription runs with a 120s ceiling that kills the hung worker and returns an honest error instead of a frozen app, the bridge ping answers IMMEDIATELY even with heavy work in flight (meta lands while the turn is still running, 150s turn ceiling, loop with catch), and the main process gained JSONL process guards so the app stays alive even when a child misbehaves. The blind normalize (bug 4) — the old '=== video' rule never counted library clips as voice carriers because clips are born without mediaKind; now the SOURCE decides (registered file + real media kind, the same PCM source the ducking reads), your clip_1 vídeo.mp4 finally counts as voice.
