# v1.7.3 — Media That Survives The Night

**Released:** 2026-11-01

- MEDIA THAT SURVIVES THE NIGHT — IMPLEMENTED: you closed the app overnight and the next day the timeline was intact but every clip had lost its media. Now the media library is durable: every imported file (yours via the Media tab, the agent's downloads, the project's creation media) is copied into the project's own media folder — idempotently, quietly, in the background. Reopening the project reborn-loads that library from the durable copies: preview thumbnails, playback and the agent's eyes all come back, and orphan clips re-attach automatically. Files you manually deleted from the folder stay honest orphans with the cause on record and a hint to re-import. Pure in-memory blobs over 512 MB are skipped with a note (hours-long gameplay does not cross the bridge); copies from disk have no cap; a failed copy never blocks editing.
- SILENT AUTOSAVE OF EVERYTHING: the media library index now travels in the very same autosaved record as the timeline and the tracks — same key, same 800 ms debounce window. Exactly as you asked, there is no 'saving... saved' toast blinking at you: autosave is completely silent, and only a real failure surfaces, as one discreet badge for 8 seconds telling you the session is still alive in memory. The autosave also learned when NOT to write: identical content is detected by a real diff (by id and by content) and the write is skipped, so nothing re-saves or re-timestamps without a change.
- THE AGENT'S EYES SURVIVE RESTARTS TOO: after a restart, reopening media through the file picker used to leave the agent's frame-capture blind ('no disk path'), even when the clip's saved anchor pointed at the living file. A 4-channel resolution cascade now finds the source every time (live blob, the clip's saved path anchor, exact name match, clip-name fallback), teaches the refusal when nothing exists, and heals the library on discovery — the found path is written back into the media item once, so every subsequent operation knows it. Suite is now 52 checks green, including the two new proof families (85 + 72 assertions) that reproduce the overnight-loss and restart-blindness scenarios end to end.
