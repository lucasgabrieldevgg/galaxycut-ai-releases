# v1.4.4 — Updates Ask First

**Released:** 2026-10-18

- UPDATES ASK FIRST: on startup the app only ANNOUNCES a new version — downloading and installing now happen exclusively with your explicit consent, and a failed install is reported instead of leaving a stuck gray overlay
- NO MORE ETERNAL 'ANALYZING…': every AI call now has hard timeouts (120s cloud / 300s local) and multi-layer watchdogs — a hung model no longer freezes the chat, the Stop button really stops, and an interrupted turn ends with an honest message instead of silence
- MEMORY TAB SHOWS ONLY REAL DATA: plan, execution log and snapshots now come from the session's real worklog — no more fabricated 'Restaurado' states; when there is nothing yet, you get an honest empty state
- ONE-COMMAND REPRODUCIBLE DESKTOP BUILD: the packaged app is now assembled by a single verified chain (site export → version-checked sync → electron-builder), closing the class of bugs where a broken www/ folder shipped inside the binary
- REMOTION TAB, HONEST SOURCES: the studio now separates 'Biblioteca de templates' (labeled curation — ready-made starting points) from 'Produção da sessão' (labeled 'only the real'), which lists exclusively code the agent actually wrote this session — with an honest empty state when nothing was generated. A live source badge updates the moment you edit the code, the preview is explicitly an 'ILLUSTRATIVE PREVIEW — not the real render', and the 'Insert into motion track' button now really inserts (labeled clip on the timeline + decision logged in the session worklog) instead of claiming an insertion that never happened
