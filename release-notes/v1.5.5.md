# v1.5.5 — The Timeline Left The Chat

**Released:** 2026-10-24

- THE TIMELINE LEFT THE CHAT: in the harness view a 264px timeline band ate almost half of the bot's area — even though the timeline already had its own tab in the rail. The band is gone: the chat and the preview stage now own the full height, and the timeline lives exclusively in its own tab (where it always had a fullscreen view with live preview). One surface per job — the bot area belongs to the bot
- EVERY CLIP NOW HAS ITS OWN EDITING SCREEN: click any clip in the Timeline tab and the new properties panel opens beside the preview — the classic editor's Inspector, finally in the harness. Subtitle text, font size, color, background box, outline, karaoke highlight, position (Topo/Centro/Rodapé presets + x/y sliders in the same convention the render uses), speed, zoom, motion template, headline, accent colors and notes — all live, all manual, all undoable via the per-turn revert that already existed
- THE AGENT IS NOW A SUBTITLE SURGEON: two new tools shipped. timeline_get_clips reads the REAL content of every clip — the caption text itself (the transcript), position, style, template, speed/zoom. timeline_update_clip edits ONE clip by id: fix a wrong word, nudge timing, reposition in the preview (top/center/bottom or a 0-1 fraction), restyle, swap the motion template. ponte_get_context now prints each caption's text and id right in the timeline block, so the external AI reads the transcript and edits it clip by clip — no more regenerate-everything to fix one box
- THE AGENT ASKS BEFORE STYLING YOUR SUBTITLES: field complaint — "I asked for captions and it never asked me which style". New golden rule in both the internal system prompt and the bridge skill: when the user asks for captions without a style, the agent MUST open a clarification card with 4-5 described presets (hormozi boxes, karaoke color-swap, cinema-box, classic yellow) and only apply after the answer. Default position: top (above the head) for 9:16 Shorts, bottom for horizontal
- MOTION GRAPHICS WENT TO FILM SCHOOL: the old cards were text fading in and out — honest, but not motion design. The code layer now ships 10 real templates, all canvas-pure and deterministic (preview and export draw the exact same frame): cinematic_title (letterbox bars, gold tracking-in type, shine sweep), word_pop (word-by-word kinetic boxes), zoom_punch (3x-to-1 impact with radial speed-lines, flash and damped shake), badge_stamp (stamped badge with squash and shine), particle_burst (hash-seeded particle explosion with glow), lower_third (broadcast bar with subline), counter_badge (count-up number with progress ring) — plus glitch_pop, spring_scale and neon_pulse. Also in this release: right-click Copy/Cut/Paste menu (Electron), selectable text in terminal/worklog/JSON, the Ponte pairing moved inside the project (the launcher now just points the way), the Model Hub tab scrollbar no longer covers the tabs, and the floating "agent executing" pill is gone (Stop stays in the composer, Revert stays per turn)
