# v1.4.3 — Real Media Durations

**Released:** 2026-10-11

- REAL MEDIA DURATIONS: imported video/audio files are probed for their true duration — a 61-minute video no longer becomes a fake 30s clip on the timeline
- REAL VIDEO PREVIEW + PLAY: the preview stage now plays your actual media file; play/pause button and Space bar work, and the playhead follows playback
- TIMELINE RULER + PLAYHEAD: a proper time ruler with adaptive tick labels (small, out of the way) and a moving needle across all tracks; click anywhere to seek
- CLIP LABELS REDESIGNED: compact names, speed/zoom/TSX badges and short durations inside clips — the big numbers are gone
- CHRONOLOGICAL CHAT: each turn now renders in true order (question, reasoning, sub-agents, tools, FINAL ANSWER LAST) — the agent's response no longer appears above the work that produced it
- PROFESSIONAL AGENT PROTOCOL (system prompt v3): the director now confirms the goal, presents a numbered plan BEFORE editing, asks for confirmation before sweeping changes (accelerating the whole video, cutting 20%+ of duration), reports each step and closes with a summary
- SILENCE REMOVAL IS REAL: timeline_remove_silences decodes the actual audio (WebAudio RMS analysis) and rebuilds the clip keeping only speech segments — with an honest confirmation gate when it would cut more than 20%
- PACING CURVE BY SEGMENTS: timeline_apply_pacing_curve accepts per-segment speeds instead of blindly applying a global 1.5x to everything
- AGENT COMMANDS ON DESKTOP: system_run_command executes ffmpeg/ffprobe/ytgrap/ollama and friends for real via the IPC bridge (whitelisted binaries); media_import_local_folder opens the native file dialog
- OLLAMA FIXED: the Model Hub connects without CORS issues in the desktop app (IPC net fetch), shows a step-by-step OLLAMA_ORIGINS guide on the web, and local models (Llama 3.2, Qwen 2.5, vision) can be DOWNLOADED with one button in the desktop app
- TYPE SAFETY RESTORED: TypeScript errors block the build again (ignoreBuildErrors: false)
