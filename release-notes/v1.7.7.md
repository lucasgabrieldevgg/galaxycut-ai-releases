# v1.7.7 — The Field's Three Wishes, Granted

**Released:** 2026-11-03

- THE FIELD'S THREE WISHES, GRANTED (the external AI that rebuilt the GTA 6 Short through the bridge, field report 03/11: 'if I could ask the app for three things: see the rendered frame, a timeline_remove_clip, and code_* freed from the plan — with those three, this edit would have taken a third of the commands'). This release ships what fits in one binary:
- timeline_remove_clip — THE DELETE THAT WAS MISSING (wish #2, and the loudest): 'there is no clip removal in this version — I tested timeline_remove_clip, timeline_delete_clip, timeline_clear_track and visual_remove_broll: none exists. An editor without delete is an editor where every mistake is permanent.' The AI invented workarounds (zero-width space to 'erase' caption text, clips parked off-frame at x:1) and the owner deleted the leftovers by hand. Now: clip_id (single) or clip_ids (BATCH — one round-trip instead of N; missing ids are reported without aborting the batch). Destructive but auditable: every removed name goes to the worklog; batches of 10+ require confirm:true (first call returns the list). What stays, stays — neighbors never move.
- plan_abort + plan_skip_step — THE DEADLOCK KEYS (wish #3, code_* freed): the approved plan got stuck on step 1 (word-sync dying at the 120s worker) and EVERY mutating tool outside the current step was refused ('not the tool of the current step') — with the abort button invisible in the UI, the plan became a padlock without a key. Now: plan_skip_step(reason) skips the unreachable step and moves on; plan_abort(reason) ends the whole plan (work already done REMAINS — only the gate dies) and unblocks a fresh proposal. The refusal itself now teaches all three paths (deviation_reason / skip / abort).
- STYLE SYMMETRY on timeline_update_clip (the wound that forced clip recreation): 'update_clip does not accept stroke color — I tested stroke_color, strokeColor, highlight_color, all refused. The red is only born at creation... changing an outline color requires recreating the clip.' Now stroke_color, font, shadow, bold, italic, highlight, highlight_color and highlight_anim all exist on update (snake_case AND camelCase accepted) — the caption restyle the skill asks for is ONE call.
- THE NAME IS THE ADDRESS: media names no longer truncate in the turn context (the field received 'Gta 6 logo - no palms…' and spent ~6 calls guessing the exact filename; the name is what timeline_add_clip resolves by). Candidate lists on name-not-found grew from 12 to 40 (the field library had 17 items — the bottom of the alphabet never showed up).
- APPIMAGE BOOT HARDENING (the owner's 'the app doesn't open'): boot.log now records EVERY boot stage from the first line of main.js (userData/logs/boot.log — the file tells the full story even if the app dies mid-boot); ozone-platform-hint=auto picks the right display backend on pure-Wayland desktops; GPU-crash fallback relaunches once in safe mode (disable-gpu) instead of showing a black window. If it ever fails to open again, the log says why.
- Served bridge skill regenerated with the new contract (15896 chars): removal, batch semantics, plan keys, style symmetry — the next field session reads the truth on /skill/galaxycut.md.
